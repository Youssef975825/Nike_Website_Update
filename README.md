# Nike Metaverse Website 🚀✨

An immersive, futuristic e-commerce web application inspired by the metaverse and cyberpunk aesthetics. Built with **React**, **TypeScript**, and **Tailwind CSS**, this project bridges the gap between virtual reality concepts and high-end sneaker fashion.

---

## 🌟 Features

* **Futuristic Hero Section:** Immersive cyberpunk grid background, glowing neon highlights, and smooth CSS floating sneaker animations.
* **Interactive Products Collection:** Curated line of high-tech sneakers with dynamic cards, ratings, and pricing.
* **Cart & Wishlist Functionality:** Seamless shopping experience allowing users to manage selected items.
* **Instant WhatsApp Integration:** Direct product ordering and size consultation via WhatsApp clicks.
* **Fully Responsive Design:** Optimized layouts for mobile devices, tablets, and desktop screens.

---

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript
* **Styling:** Tailwind CSS
* **Animations & UI Effects:** Custom CSS Keyframes & Glassmorphism
* **Deployment:** Vercel

---

## 🚀 Getting Started

To run this project locally on your machine, follow these steps:

### Prerequisites
Make sure you have **Node.js** and **npm** installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Youssef975825/Nike_Website_Update.git
   ```

2. Navigate to the project directory:

```Bash
cd nike-metaverse-website
```
3. Install dependencies:

```Bash
npm install
```
4. Run the development server:

```Bash
npm run dev
```
